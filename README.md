# StyleTry

Telegram bot for shoppers to upload a photo and preview outfits from a brand catalog or user uploads as static images or short non-sexual animated previews; save and favorite locally.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
